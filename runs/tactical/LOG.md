## For the MVP lead

Findings worth adopting, with evidence; each becomes an MVP backlog item and a paired test (D-025) before
any default changes.

- Measurement, not a model finding: one slice's direction AUC has an error of about 0.06-0.12 (n_eff 20-40), the 5-slice mean about 0.03; seed sd 0.04-0.05 inside a slice. A 0.02-0.03 effect needs far more independent slices (30-50) or longer validation blocks. logreg_lags on the same blocks is 0.554 (0.42-0.67 per slice): not evidence of skill.
- **2026-10-08 (H23):** on the long block a logistic regression on 7 textbook indicators at the window's last bar beats the
  network's direction AUC by ~0.05 (0.570 vs 0.521, 3 held check slices). The model loses signal a linear readout keeps.
- **2026-10-09 (H25, H26):** on the long block learned indicator periods never beat textbook ones (G: 0.001 +-0.006; thin readout: -0.002 +-0.003), and a network with no indicators equals the 14-family default on direction with better log loss. Evidence against D-031's learnable-indicator premise in the window model; a candidate for an MVP paired test (no-indicator input vs the default) before NT-050's sweep spends GPU on indicator periods.
- **2026-10-09 (H27, H28):** a 13-feature logistic regression (scale-free last-bar indicators and returns) beats the default network's direction AUC by +0.036 [+0.006,+0.067] on the same blocks in 3 s of CPU; a rebuilt minimal Keras model equals it, and an MLP or a GRU on top adds nothing (24 slices). Candidate MVP item: a regression baseline as a model in the registry, and the leaderboard's frozen-twin comparison against it.
- **2026-10-09 (H28, H35, H36):** on BTC/USDT 1-minute, 10-20 min direction, no network built bottom-up (MLP, GRU, PatchTST-lite, TCN; 11.5 d to 3 y of training) beats a 13-feature logistic regression (0.570 mean3 AUC, 24 slices). Networks add only volatility information (+0.03-0.05 Spearman over trailing realised vol). Candidate MVP items: a regression direction model and a volatility network in the registry.
