## TEST-1: Leaderboard metric formulas have no unit test: a sign-flipped Sharpe, and a sharpe_net computed from gross returns, both pass the whole suite

- **Severity:** P1. **Status:** confirmed. **Type:** test-gap. **CPU cost:** instant. **Placement:** new item CPU-09.
- **Files:** `src/neural_trade/strategy/performance.py`, `tests/test_backtest.py`

The only Sharpe assertion in the suite is `sharpe_net == 0` on a flat equity curve (tests/test_backtest.py:124), and a sign flip keeps that true.
