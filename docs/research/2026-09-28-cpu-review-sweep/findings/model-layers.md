## MODEL-2: RSI periods are EMA spans (alpha = 2/(n+1)), not Wilder periods: the configured RSI 9/14/21 compute Wilder RSI 5/7.5/11

## MODEL-3: Bollinger std is sqrt(1-alpha) too small: the '+-2 sigma' bands sit at +-1.81/1.90/1.92 sigma of the EW std

- **Severity:** P3. **Status:** confirmed. **Type:** bug. **CPU cost:** instant. **Placement:** addition to NT-046, NT-043.
- **Files:** `src/neural_trade/models/layers/learnable_indicators.py`

**Description.** The layer takes the variance as EWMA_alpha((x_t - mean_t)^2), measuring deviation from the already-updated mean (learnable_indicators.py:164-168 batched, :254-258 scan). Since x_t - mean_t = (1-alpha)(x_t - mean_{t-1}), each increment is alpha(1-alpha)^2 d^2 instead of the EW-variance recursion's alpha(1-alpha) d^2. The resulting std is exactly sqrt(1-alpha) times pandas ewm(span, adjust=False).std(bias=True), which equals the Finch EW std. Upper/lower bands and %B therefore use about 1.8-1.9 sigma, not 2 sigma. The network can learn around a fixed scale, so impact is low, but the features do not match their names.

**Failure scenario.** Input: BB period 10 on any real window. Output: the 'upper band' is mean + 1.81 x EW std, and %B saturates at the band edges earlier than a standard EW Bollinger %B.

**Evidence (finder, reproduced).** Ran agents/model-layers/bb_std.py on 256 real windows. Layer std / pandas ewm(span=p, adjust=False).std(bias=True): median 0.905/0.951/0.961 for p = 10/20/25, equal to sqrt(1-alpha) = 0.905/0.951/0.961. The same result holds against a hand-written Finch recursion. Vs rolling(p).std(ddof=0) the ratio is 1.08-1.15, since EW and simple bands are different by design. Candidate fix in the copy (divide sq_dev by (1 - alpha_bb) in both paths), fix_checks.py: median ratio 1.0000, max rel err 3.3e-5/5.9e-5/7.2e-5. The 26 tests in test_learnable_indicators, registries/test_layers, test_models and test_physics_terms_bounded pass.

**Verifier (reproduced): confirmed.** Re-read learnable_indicators.py:164-168 (sq_devs = (x - bb_mean)^2 with the already-updated mean, then an EWMA) and :254-258 (the same in the scan path). The algebra: x_t - m_t = (1-a)(x_t - m_{t-1}), so the layer's variance recursion is V_t = (1-a)V_{t-1} + a(1-a)^2 d^2. With V_0 = 0 this is exactly (1-a) times the Finch EW variance, which equals pandas ewm(adjust=False).var(bias=True). I ran agents/verify-model-layers/v2_rsi_bb_conv.py (64 windows, both EWMA_IMPL modes, meta_adjust 0). Layer std / Finch std has median 0.9045/0.9512/0.9608 for p = 10/20/25, equal to sqrt(1-a) = 0.9045/0.9512/0.9608. pandas and Finch agree to 1e-16, so the bands sit at +-1.809/1.902/1.922 EW sigma. Refutation attempts: the docstring states no convention, and 'EWMA of the squared deviation from the updated EMA' is a common implementation. The network can absorb the near-constant factor, which varies only slightly per window through meta_adjust. No backlog item covers it.

**Verifier corrections.** This is a naming/convention defect with little effect on the model; keep it at P3 and call it a convention mismatch rather than wrong numbers. Where it matters is NT-043/NT-048's 'Bollinger lines next to the textbook': with a standard (SMA or Finch EW) reference, the figure shows a band-width gap of 4-10% at zero learning. Fix: fold it into NT-046's per-family reference tests. The doc route (the entry states the bands as mean +- 2*sqrt(1-a)*sigma_EW, and NT-043 draws the reference with the family's own formula) changes no numbers. The code route (divide sq_dev by (1 - alpha) in both paths) changes inputs slightly, so bundle it with the MODEL-1 value change under one A/B. MVP growth point 5 via growth point 1; during NT-046. Acceptance as proposed. The identity holds exactly for every t >= 1, so t >= 1 can replace t >= 5 in the check against pandas ewm(span=p, adjust=False).std(bias=True) (code route) or against sqrt(1-a) times it (doc route), within 1e-3 relative, in both EWMA_IMPL modes. cpu_cost: instant.

**Backlog check (finder).** Not covered by any BACKLOG, ROADMAP or STATUS item.

**Fix sketch.** sq_devs = [tf.square(x - m) / (1.0 - a[:, None]) for m, a in zip(bb_mean, bb)] at line 164, and the same with bb_alpha at line 255. Alternative: document the bands as +-2*sqrt(1-alpha)*sigma. Bundle it with MODEL-1 as one feature-definition change, since it changes model inputs slightly.

**Acceptance (proposed).** (1) A test in tests/test_learnable_indicators.py: (upper - mean)/2 from the layer equals pandas ewm(span=p, adjust=False).std(bias=True) within 1e-3 relative, for t >= 5 on 64 real windows, in both EWMA_IMPL modes. (2) test_batched_layer_equals_per_indicator_layer_values_and_gradients and test_matrix_and_scan_layers_agree still pass.
