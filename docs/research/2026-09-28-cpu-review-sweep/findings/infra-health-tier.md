## INFRA-4: Backtest loop: numpy scalar indexing and np.clip on a Python float cost half the time; a 2-line change makes backtest() 2.1x faster with bitwise-identical results

- **Severity:** P2. **Status:** confirmed. **Type:** perf. **CPU cost:** instant. **Placement:** new item CPU-21.
- **Files:** `src/neural_trade/strategy/backtest.py`, `src/neural_trade/notebook/backtest_ui.py`

**Description.** run_backtest's per-bar Python loop (strategy/backtest.py:199) indexes four numpy arrays on every bar (:200). On every entry it calls `float(np.clip(order.size_frac, 0.0, 1.0))` (:208), and np.clip on a Python scalar goes through numpy's slow wrapper path. backtest() runs the strategy, buy-and-hold, always-flat and random_same_frequency.
